# Clawd 貼圖

### 👉 [打開貼圖鍵盤](https://ji0987.github.io/clawd-stickers/)

像素風動態貼圖鍵盤，手機、電腦都能用：

- **點一下**：手機會開啟分享選單，可以直接傳到聊天 App；電腦會複製，貼到 Gmail、Notion 是動圖，貼到 Discord、Slack 是會展開的 GIF 連結
- **長按**（電腦按右鍵）：放大預覽、加入最愛
- 上方可以搜尋，下方切換分組，常用的會自動出現在「最近」
- 手機用瀏覽器選單的「加到主畫面」，就能像 App 一樣開啟，看過的貼圖離線也能用

本站為個人非官方創作，與 Anthropic 無關。
